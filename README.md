# Групповой анализ: карьера и бизнес — лендинг

Адаптивный статический сайт по презентации «Групповой анализ: карьера и бизнес» (10 экранов).

- Настольная версия повторяет макет слайдов 16:9: фон, рамка, расположение текста, тонкие линии, микронадписи, фотография.
- Мобильная версия перестроена в вертикальный формат с читаемыми шрифтами, без изменения содержания.
- Все тексты настоящие HTML-тексты. Работают ссылки на Telegram, сайт и звонок по телефону.
- Данные группы: 15 января 2027, 2 000 ₽ за встречу, раз в неделю 1,5 часа, до восьми человек.

## Как опубликовать в Vercel

1. Распакуйте архив.
2. На vercel.com откройте Add New → Project и загрузите папку сайта через Git-репозиторий или Vercel CLI.
3. Framework Preset: Other; Build Command: пусто; Output Directory: `.`.
4. После публикации проверьте кнопки и адрес сайта. Это новый сайт, существующий проект не изменяется.

Для просмотра локально откройте `index.html` в браузере. Для предпросмотра с локальным сервером: `python3 -m http.server 8000`.

Внешняя зависимость: Google Fonts (Inter). Если сервис недоступен, браузер использует установленный системный шрифт. Файлы шрифтов не входят в архив.
